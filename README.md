# Familienbuero-Pro

## Geschenkbox für Jens · FAST 365

Die Geschenkpräsentation liegt vollständig in [`index.html`](index.html):

1. Die gesamte Geschenkbox anklicken.
2. Das Pop-up-Buch öffnet sich mit Konfetti.
3. Den leuchtenden Anhänger oder „Jens’ Projektakte öffnen“ anklicken.
4. In der Projektakte das Repository ansehen oder als ZIP herunterladen.

Die HTML-Datei enthält beide Illustrationen, CSS und JavaScript. Sie benötigt
keine Installation, keinen Build und keine externen Bild- oder Schriftdateien.
Zum Ansehen `index.html` herunterladen und in Chrome öffnen.

Für eine lokale Vorschau über HTTP im Repository ausführen:

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

Die Vorschau läuft anschließend lokal auf Port 8765.

Hinweise für die Veröffentlichung und die Übergabe an Claude Code stehen in
[`CLAUDE_HANDOFF.md`](CLAUDE_HANDOFF.md).

Die Seite ist eine persönliche Geschenkpräsentation. Die geplante PWA mit
Office-Funktionen und Familienakte Pro ist damit noch nicht implementiert.
